# Barry Family PCS Planner

A polished, family-friendly Next.js planning app for managing a PCS move from Arnold, MD to Hurlburt Field / Fort Walton Beach.

## Features
- Dashboard with KPI cards plus Monday kickoff actions and owner workload visibility
- Master Plan task manager with filtering, sorting, due-date awareness, inline status edits, and a Monday-style board view
- House Sale milestone tracker (target vs actual)
- Rental comparison workspace with computed fit scores and shortlist toggles
- Budget tracker with estimate vs actual variance totals
- Contacts manager
- Onboarding/help module
- Local persistence (localStorage) for all planner modules
- Optional Supabase sync for tasks when env vars are configured

## Run locally
```bash
npm install
npm run dev
```

## Optional Supabase setup (tasks sync)
1. Copy `.env.example` to `.env.local` and provide values:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
2. In Supabase SQL editor, create a `public.tasks` table that supports these fields used by the app:

```sql
create table if not exists public.tasks (
  id bigint generated by default as identity primary key,
  task text not null,
  phase text,
  category text,
  owner text,
  status text,
  priority text,
  dueDate date,
  target date,
  dependency text,
  notes text
);
```

> The app works without Supabase; it will continue using local demo data + localStorage.

### If the app says “Cloud sync is off. Working locally in your browser only.”
- Make sure both `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are set in `.env.local`.
- Restart the dev server after editing env vars.
- Confirm the `public.tasks` table exists with the schema above.


## Deploy
Deploy to Vercel with the same environment variables if you want Supabase task sync enabled.
